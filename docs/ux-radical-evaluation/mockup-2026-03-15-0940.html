H3 — Frequency bar: taller and full-width

Remove the 38% max-width cap. Let bars scale to 100% proportionally. Increase height from 2px to 4px. The encoding stays qualitative — no counts, no targets — but relative differences become legible at a glance.

Two changes only:

barWidth: * 38 → * 100

Bar height: h-0.5 → h-1

No count numbers added — the bar remains a qualitative signal. Showing a precise count would create an implicit target, which contradicts Clarity's philosophy. The bar communicates rhythm; the user feels the pattern, not measures it.

H4 — Period selector: enclosed pill group

Replace the floating dot-separated text buttons with an enclosed segmented pill. Same pattern as the Settings S1 Theme toggle — visual consistency, clear selection state.

Consistency note: This is the same pattern as the Settings S1 Theme toggle recommendation. Both can use a shared component — or at minimum the same exact Tailwind classes — so the pattern is visually identical across the app. The active fill uses bg-stone-800 text-white light / bg-stone-200 text-stone-900 dark — the primary button token, which means "selected / confirmed" throughout Clarity.
