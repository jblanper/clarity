B3 — Moments as editable chip grid

Moments are not the same as habits. They're short, informal labels — the same kind of thing that appears as chips in the check-in form. Rendering them as a list discards visual language the user already knows. This proposal restores it.

B4 — ✿ Joyful as amber pill tag

The current joy indicator uses a second-line text button with verbose instructional copy. This proposal replaces it with a small amber ✿ Joyful pill tag — present only when active, reading like a quality tag on a notebook entry. The toggle moves into the action tray: one label, both states, visual styling carries the meaning.
