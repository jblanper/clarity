P3 — Add-moment inline form

The text input's py-2 gives ~36px visual height. The Add button has min-h-[44px]. Adding min-h-[44px] to the input fixes the proportional mismatch and brings the input into 44px touch-target compliance.

Current

Input: ~36px (py-2). Button: 44px. The button is visibly taller — it dominates the row.

Proposed

Input: 44px (min-h-[44px]). Both elements share the same height. The row reads as a coherent pair.

P4 — Reflection textarea

The textarea uses border-stone-300 in light mode — one step heavier than the Calma "Card, input" border token (stone-200). The heavier border adds unnecessary formality to the softest, most optional section of the form.

Current

Reflection

Border: stone-300 in light mode. Heavier than spec (stone-200). Adds boxed, mandatory-field energy to an optional, reflective input.

Proposed

Reflection

Border: stone-200 in light mode (Calma spec). Focus: stone-400 (lighter than before). Softer presence — the textarea invites rather than frames.
