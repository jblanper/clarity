Notes on C v1 vs C v2

C v1 — 4 weight levels (300/400/500/600): Empty days use the same grey family as low-activity habit days. Hard to distinguish at small sizes — four weight grades is too many.

C v2 — Ghost + 3 tiers: Empty days are ghosted (very light, receding). Active days use 3 tiers only: low (400, stone), medium (600, stone), bold (700, stone or amber). The calendar breathes — empty days disappear, logged days speak clearly.
