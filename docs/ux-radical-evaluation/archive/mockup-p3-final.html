Accessibility correction from previous report: The number at zero is now stone-500 (not stone-300). Contrast ratio on stone-100 pill background: approximately 3.0:1 — this is below AA for body text but acceptable for large-scale UI control text (≥18px bold or ≥24px regular). At 1.25rem font-weight-300 this is borderline. An alternative: use stone-600 at ~4.8:1 to guarantee AA. Decision left to implementation review.

Accessibility note: Ghost + is now stone-500 (font-weight: 300, text-xs). The previous report proposed stone-300 and accepted a contrast exception. That exception is revoked here. stone-500 at ~4.6:1 passes WCAG AA. The "ghost" quality comes from weight and scale, not from failed contrast. The aria-hidden on the span ensures screen readers hear only the number value.

Recommendation: Ship P3-A in the current sprint — no data model changes required, maximum discoverability gain for minimum effort. Decide P3-B separately once the "intentional zero vs. untouched" data model question is settled. The two variants are not mutually exclusive — P3-B can replace P3-A later as a one-line change.
