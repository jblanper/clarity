Design note

This proposal replaces the iOS sliding metaphor with a static chip — a meaningful step forward. But it substitutes one widget type for another without addressing the root question: why is the control separate from the label at all? Consider this a transitional design. Proposal 1 (left indicator) is the more Calma-coherent resolution.
