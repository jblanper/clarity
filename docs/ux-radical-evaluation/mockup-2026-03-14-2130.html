S1 — Theme toggle

Segmented pill control

Replaces the two anonymous text buttons with a contained segmented control. The active option gets a filled indicator using the primary button token. The enclosure makes the control self-explanatory — two options, one selected.

Implementation note

The filled active state uses the primary button token — bg-stone-800 dark:bg-stone-200 text-white dark:text-stone-900. Stone rather than amber is correct here — theme is a structural preference, not an emotional selection. No logic changes required, only the wrapper and button classes.

S2 — Your data

Sub-labels + tertiary initiating actions

Adds BACKUP and RESTORE sub-labels to make the section scannable. Drops the initiating action buttons from full-width secondary to tertiary weight — they open system dialogs, not perform primary actions. The Import confirm button (after file selection) retains primary weight.

S3 — Reset

Button affordance + human copy + red at the terminal action

Three changes: (1) the bare text link becomes a proper tertiary button with amber border — gives it affordance without urgency; (2) copy shifts from technical ("factory defaults") to human ("Start fresh"); (3) the confirmation action escalates to red — the only moment where irreversibility is crossed. Calma: "Red signals permanent destructive actions only."

Confirmation text: shorter and direct. Confirmation action: "Yes, reset everything" → "Yes, start fresh" in text-red-700 dark:text-red-400. Cancel: "Cancel" → "Keep my data".
