Proposal 2: The Weave

Density via line thickness. Each day is a vertical thread. The 'weave' grows stronger on active days.

Proposal 3: The Petals

Density via scale and 'bloom'. Organic circles that vary in size. Amber days are filled; others are subtle outlines.

Proposal 4: The Mist

Density via opacity and blur. A 'Ma' day is a faint haze. An active day is a grounded stone.

Proposal 5: The Field

Density via typographic texture. Using slash symbols to create a cross-hatch feeling. More slashes = more activity.
